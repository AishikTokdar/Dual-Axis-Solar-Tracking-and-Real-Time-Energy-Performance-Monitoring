# Mechanical assembly

Print-ready third-party parts are in [STL](STL/). See [attribution and licensing](ATTRIBUTION.md) before reuse.

| Part family | Files | Purpose |
|---|---|---|
| MG995_TILT_PAN | Base block, base lid, corner, vertical arm, vertical bracket | Servo pan-tilt structure |
| SOLAR_PANEL | Bottom cover, corner, side rails, support | Panel mounting |

The original build notes specify PLA, 15% infill, and a Creality CR-10 Smart Pro. Choose support and orientation per part. Confirm dimensions, servo fit, cable clearance, and panel retention on the actual assembly. STL names refer to MG995 geometry; fitted servo compatibility must be checked independently.
